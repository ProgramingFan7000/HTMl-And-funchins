# HTML-And-Funchins

A simple starter page for learning basic HTML.

This project shows:
- HTML headings from `h1` to `h6`
- Paragraphs with the `p` tag
- Images using the `img` tag
- A basic styled layout using CSS

Open `main.html` in your browser to see the page, and edit it to practice your own content.
